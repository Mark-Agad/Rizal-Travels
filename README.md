# 📜 Explore Rizal's Journey Through Europe

An interactive historical travelogue web application tracking Dr. José Rizal’s 19th-century journey across Europe. Explore his routes, cities visited, and key historical events along his path.

🚀 **Live Demo:** [rizal-europe-travels.netlify.app](https://rizal-europe-travels.netlify.app)

---

## 🛠️ Tech Stack

* **Framework:** React / Vite / TanStack Start
* **Styling:** Tailwind CSS
* **Fonts:** Cormorant Garamond & Work Sans

---

Follow these steps to set up and run the project locally on your machine:
